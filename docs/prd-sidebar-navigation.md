# PRD: Sidebar Navigation

**Дата**: 2026-08-24
**Статус**: Draft

## Цель

Дать залогиненному пользователю постоянную панель навигации (справа), видимую на аналитической домашней странице и на доске проекта, через которую он управляет своими проектами и заявками на вступление — без этого пользователю негде создать проект, вступить в чужой по коду или увидеть, кто состоит в открытом проекте.

## Пользовательские сценарии

- Пользователь открывает любую защищённую страницу -> в сайдбаре справа видит список "мои проекты" (проекты, где он owner или member).
- Пользователь вводит текст в поле поиска сайдбара -> список проектов фильтруется по названию.
- Пользователь нажимает "Создать проект" в сайдбаре -> открывается форма создания, после успеха проект появляется в списке.
- Пользователь вводит код в форму "Присоединиться по коду" в сайдбаре и отправляет -> заявка создаётся со статусом pending.
- Пользователь открывает вкладку/раздел "мои заявки" в сайдбаре -> видит все свои заявки и их статусы (pending / approved / rejected), может скрыть/удалить отклонённую.
- Пользователь, являющийся owner хотя бы одного проекта с pending-заявками, видит в сайдбаре счётчик/бейдж количества таких заявок.
- Owner открывает список pending-заявок по своим проектам в сайдбаре и видит для каждой Approve/Reject.
- Пользователь кликает на проект в списке -> переходит на доску этого проекта (`/dashboard/:projectId`), сайдбар подгружает блок "Люди" — участников именно этого проекта (роль каждого).
- Пользователь на странице без открытого проекта (Home) видит блок "Люди" пустым/неактивным — участники привязаны к конкретному открытому проекту.
- Пользователь нажимает кнопку "Информация" при открытом проекте -> видит панель с названием проекта, кодом приглашения и своей ролью в нём.
- Неавторизованный пользователь не видит сайдбар (недоступен вне защищённых страниц).

## В скоупе

- Постоянный сайдбар справа, общий layout для Home и Dashboard.
- Список "мои проекты" + поиск по названию (клиентская фильтрация).
- Форма "создать проект" и форма "присоединиться по коду" внутри сайдбара.
- Раздел "мои заявки": статусы (pending/approved/rejected), скрытие/удаление отклонённой заявки.
- Раздел pending-заявок по проектам пользователя (для owner) с действиями Approve/Reject и счётчиком/бейджем.
- Блок "Люди" — участники текущего открытого проекта (email, роль); пуст/неактивен, если проект не открыт.
- Кнопка "Информация" с панелью данных текущего открытого проекта (название, код, роль пользователя).
- Отображение ошибок при создании проекта/подаче заявки (например, "заявка уже отправлена", "вы уже в проекте").

## Не в скоупе

- Аналитика/метрики по задачам — отдельная фича (`docs/prd-home-analytics.md`).
- Канбан-доска и сами задачи — отдельная фича (`docs/prd-project-dashboard.md`).
- Управление ролями участников, исключение участника из проекта, удаление/архивация проекта.
- Приглашение по email, push/email-уведомления.
- Поиск/просмотр чужих проектов без кода.

## Технические ограничения

- Список/создание проектов и весь жизненный цикл заявок используют уже готовые API: `GET/POST /projects`, `POST /projects/join`, `GET /join-requests`, `DELETE /join-requests/:id`, `GET /join-requests/pending`, `GET /join-requests/pending/count`, `POST /join-requests/:id/approve|reject`.
- Блок "Люди" требует нового эндпоинта — списка участников конкретного проекта (в проекте пока нет `GET /projects/:id/members`).
- Сайдбар должен оставаться на экране при переходах между Home и Dashboard — требует общего layout-компонента на фронтенде вместо независимых страниц.
- Доступ к сайдбару и вызовы соответствующих API требуют валидного JWT.

## Критерии готовности

- [ ] Авторизованный пользователь видит в сайдбаре список своих проектов на Home и на Dashboard.
- [ ] Поиск в сайдбаре фильтрует список проектов по названию.
- [ ] Пользователь может создать проект через сайдбар и увидеть его в списке.
- [ ] Пользователь может подать заявку на вступление по коду через сайдбар.
- [ ] Раздел "мои заявки" показывает актуальные статусы всех заявок пользователя.
- [ ] Пользователь может скрыть/удалить отклонённую заявку.
- [ ] Owner видит счётчик/бейдж pending-заявок по своим проектам и может Approve/Reject прямо из сайдбара.
- [ ] При открытом проекте (`/dashboard/:projectId`) блок "Люди" показывает участников именно этого проекта с ролями.
- [ ] Без открытого проекта (Home) блок "Люди" отображается пустым/неактивным, без ошибок.
- [ ] Кнопка "Информация" открывает панель с названием, кодом и ролью пользователя для текущего открытого проекта.
- [ ] Ошибки создания проекта/подачи заявки отображаются понятным сообщением.
- [ ] Неавторизованный пользователь не видит сайдбар и не может вызвать его API.
