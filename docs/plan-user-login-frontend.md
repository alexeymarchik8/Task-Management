# Plan: User Login Frontend

**PRD:** docs/prd-user-login.md
**Дата:** 2026-08-23

## Фазы реализации

### Фаза 1: Страница логина с формой и обработкой ошибок

**Цель:** Минимальный рабочий путь — пользователь вводит email/пароль, при успехе попадает в приложение с сохранённой сессией, при ошибке видит единое сообщение об ошибке авторизации.
**Затрагивает:** frontend
**Задачи:**

- [ ] Тест: `loginUser()` (`src/api/authApi.ts`) отправляет `POST /auth/login` и возвращает `{ id, email, token }` при успехе, бросает `ApiError` при 401.
- [ ] Тест: `LoginForm` при сабмите с валидными данными вызывает `onSuccess` с ответом API; во время запроса кнопка задизейблена и показывает состояние загрузки.
- [ ] Тест: `LoginForm` при ошибке авторизации (401) показывает единое сообщение об ошибке (`role="alert"`), не указывающее, что именно неверно — email или пароль.
- [ ] Реализовать `loginUser()` в `src/api/authApi.ts` по аналогии с `registerUser()`.
- [ ] Реализовать `LoginForm` (`src/components/LoginForm.tsx`) и страницу `Login` (`src/pages/Login.tsx`) по аналогии с `RegistrationForm`/`Register`: поля email/пароль, вызов `loginUser`, при успехе — `useAuth().login()` и редирект на `/dashboard`.

**Когда готова:** Страница логина отправляет верные email/пароль и переводит пользователя в `/dashboard` с сохранённой сессией; неверные email/пароль показывают одно и то же сообщение об ошибке авторизации, не раскрывающее, какой из факторов не совпал.

### Фаза 2: Маршрут и взаимная навигация между логином и регистрацией

**Цель:** Страница логина доступна по маршруту `/login`, уже авторизованный пользователь не видит её повторно, между страницами логина и регистрации есть переход в обе стороны.
**Затрагивает:** frontend
**Задачи:**

- [ ] Тест: авторизованный пользователь при переходе на `/login` редиректится на `/dashboard` (аналогично поведению `/register`).
- [ ] Тест: страница `/login` содержит ссылку на `/register` («Нет аккаунта? Зарегистрироваться»).
- [ ] Тест: страница `/register` содержит ссылку на `/login` («Уже есть аккаунт? Войти»).
- [ ] Добавить маршрут `/login` в `src/App.tsx`.
- [ ] Добавить ссылки-переходы на `Login.tsx` и `Register.tsx`.

**Когда готова:** `/login` работает как отдельный маршрут с редиректом для уже авторизованных пользователей; со страниц логина и регистрации можно перейти друг на друга.
