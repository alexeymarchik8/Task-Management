# Plan: Home Page Analytics

**PRD:** docs/prd-home-analytics.md
**Дата:** 2026-08-24

## Фазы реализации

### Фаза 1: Агрегирующий эндпоинт — сводка по всем проектам

**Цель:** Минимальный рабочий путь — бэкенд умеет посчитать сводку по задачам всех проектов текущего пользователя.
**Затрагивает:** backend
**Задачи:**

- [ ] Тест: `GET /analytics/summary` возвращает общее количество задач и разбивку по 5 статусам по всем проектам, где пользователь participant.
- [ ] Тест: пользователь без проектов получает нулевую сводку без ошибки.
- [ ] Тест: задачи чужих проектов (где пользователь не participant) не попадают в сводку.
- [ ] Создать `modules/analytics/` (repository + controller + route) с агрегацией через Prisma.
- [ ] Подключить роут в `app.ts`, защитить `verifyToken`.

**Когда готова:** Тесты фазы проходят; эндпоинт отдаёт корректную общую сводку только по проектам текущего пользователя.

### Фаза 2: Разбивка по каждому проекту

**Цель:** Сводка включает не только общие цифры, но и разбивку по каждому проекту пользователя.
**Затрагивает:** backend
**Задачи:**

- [ ] Тест: ответ включает по каждому проекту пользователя количество задач по статусам.
- [ ] Тест: % выполненных задач считается корректно (done / всего, с округлением) как в общей сводке, так и по каждому проекту.
- [ ] Расширить `modules/analytics` — добавить per-project разбивку в ответ эндпоинта.

**Когда готова:** Тесты фазы проходят; ответ `GET /analytics/summary` содержит и общую сводку, и разбивку по каждому проекту.

### Фаза 3: Страница Home — сводные метрики

**Цель:** Авторизованный пользователь видит общую сводку по задачам на `/homepage`.
**Затрагивает:** frontend
**Задачи:**

- [ ] Тест: рендер общего количества задач, разбивки по статусам и % выполненных на `/homepage`.
- [ ] Тест: неавторизованный пользователь при переходе на `/homepage` перенаправляется на `/login`.
- [ ] `api/analyticsApi.ts` — `getAnalyticsSummary`.
- [ ] `pages/Home` — layout + карточки сводных метрик, защищённый роут `/homepage`.

**Когда готова:** Тесты фазы проходят; авторизованный пользователь видит сводку по всем своим проектам на `/homepage`.

### Фаза 4: Список проектов с разбивкой, переход на доску, пустое состояние

**Цель:** Со страницы Home можно оценить каждый проект отдельно и сразу перейти в него.
**Затрагивает:** frontend
**Задачи:**

- [ ] Тест: список проектов с мини-разбивкой по статусам рендерится корректно по данным эндпоинта.
- [ ] Тест: клик по проекту в списке ведёт на `/dashboard/:projectId`.
- [ ] Тест: пользователь без проектов/задач видит пустое состояние без ошибок и падений страницы.
- [ ] Добавить в `pages/Home` список проектов с разбивкой + переход по клику + пустое состояние.

**Когда готова:** Тесты фазы проходят; все критерии готовности PRD выполнены.
