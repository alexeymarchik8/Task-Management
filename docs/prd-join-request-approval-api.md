# PRD: Join Request Approval API

**Дата**: 2026-08-23
**Статус**: Draft

## Цель

Дать владельцу проекта возможность просматривать и одобрять/отклонять заявки на присоединение к своим проектам, включая счётчик непросмотренных заявок.

## Пользовательские сценарии

- Owner запрашивает список pending-заявок по своим проектам -> получает список заявок с данными заявителя.
- Owner одобряет заявку -> заявитель становится участником проекта (role: member), статус заявки меняется на approved.
- Owner отклоняет заявку -> статус заявки меняется на rejected.
- Пользователь, не являющийся owner проекта, пытается одобрить/отклонить заявку по этому проекту -> получает ошибку доступа, статус не меняется.
- Owner запрашивает количество непросмотренных pending-заявок по своим проектам -> получает число для отображения счётчика/бейджа.

## В скоупе

- Эндпоинт получения списка pending-заявок по проектам, где текущий пользователь — owner.
- Эндпоинт approve заявки: меняет статус на approved и добавляет пользователя в проект с ролью member.
- Эндпоинт reject заявки: меняет статус на rejected.
- Проверка прав: approve/reject доступны только owner'у проекта, к которому относится заявка.
- Эндпоинт получения количества pending-заявок по проектам текущего пользователя (для счётчика/бейджа).

## Не в скоупе

- Создание проектов и подача заявок (отдельные PRD).
- Email/push-уведомления.
- Отзыв уже одобренной заявки, исключение участника.
- Пометка заявок как "просмотренные" (детализация read/unread) — счётчик считает все pending-заявки.

## Технические ограничения

- Эндпоинты защищены JWT (используется middleware из Project Creation API).
- Approve/reject — атомарная операция: обновление статуса заявки и (для approve) добавление участника происходят согласованно, без промежуточного некорректного состояния.

## Критерии готовности

- [ ] Owner получает список pending-заявок только по своим проектам.
- [ ] Пользователь, не являющийся owner, не может получить список pending-заявок чужого проекта.
- [ ] Approve заявки переводит её в статус approved и добавляет заявителя в проект с ролью member.
- [ ] Reject заявки переводит её в статус rejected, участник не добавляется.
- [ ] Попытка approve/reject заявки не-владельцем проекта возвращает ошибку доступа и не меняет статус заявки.
- [ ] Owner может получить количество pending-заявок по своим проектам для отображения счётчика.
