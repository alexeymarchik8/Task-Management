# Plan: Join Project by Code API

**PRD:** @docs/prd-join-project-by-code-api.md
**Дата:** 2026-08-23

## Фазы реализации

### Фаза 1: Модель JoinRequest и подача заявки

**Цель:** Авторизованный пользователь может подать заявку на вступление в проект по коду; заявка сохраняется со статусом pending, дубликаты и некорректные случаи отклоняются.
**Затрагивает:** database, backend
**Задачи:**

- [x] Добавить модель `JoinRequest` в `prisma/schema.prisma` (id: uuid, userId, projectId, status: pending/approved/rejected, createdAt) и сгенерировать миграцию
- [x] Реализовать `POST /projects/join` (или аналог) с `verifyToken`: принимает код проекта, ищет проект по коду, возвращает 404 "проект не найден" при отсутствии
- [x] Валидация: если пользователь уже owner/member проекта — ошибка "вы уже в проекте", заявка не создаётся
- [x] Валидация: если у пользователя уже есть pending-заявка на этот проект — ошибка "заявка уже отправлена", дубликат не создаётся
- [x] При прохождении валидаций — создать `JoinRequest` со статусом pending, вернуть заявку в ответе

**Когда готова:** Тесты подтверждают: успешное создание заявки по валидному коду; ошибка при повторной pending-заявке без дубликата; ошибка при заявке уже состоящего в проекте пользователя; ошибка "проект не найден" при несуществующем коде.

### Фаза 2: Список и удаление заявок пользователя

**Цель:** Пользователь может посмотреть все свои заявки и скрыть/удалить отклонённую заявку.
**Затрагивает:** backend
**Задачи:**

- [x] Реализовать `GET /join-requests` (или аналог) с `verifyToken`: возвращает все заявки текущего пользователя со статусами (pending/approved/rejected)
- [x] Реализовать `DELETE /join-requests/:id` с `verifyToken`: удаляет/скрывает заявку текущего пользователя только если её статус rejected
- [x] Проверка владения заявкой (заявка принадлежит текущему пользователю) при удалении

**Когда готова:** Тесты подтверждают: список заявок возвращает актуальные статусы; удаление rejected-заявки убирает её из списка; попытка удалить чужую или не-rejected заявку отклоняется.
