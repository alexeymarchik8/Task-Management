# PRD: Project Creation API

**Дата**: 2026-08-23
**Статус**: Draft

## Цель

Дать авторизованному пользователю возможность создать проект и получить список своих проектов через API — базовая сущность, на которую опираются присоединение по коду и домашняя страница.

## Пользовательские сценарии

- Авторизованный пользователь отправляет запрос на создание проекта с названием -> проект создаётся с уникальным 8-символьным кодом, пользователь становится owner.
- Авторизованный пользователь запрашивает список своих проектов -> получает проекты, где он owner или member.
- Неавторизованный пользователь пытается создать проект или получить список проектов -> получает ошибку авторизации, проект не создаётся.
- Пользователь пытается создать проект без названия -> получает ошибку валидации, проект не создаётся.

## В скоупе

- JWT-middleware для проверки авторизации (`verifyToken`), применяемое к роутам проекта.
- Модель `Project` (Prisma): id (uuid), name, code (уникальный, 8 символов, буквы+цифры), ownerId, createdAt.
- Модель участия пользователя в проекте с ролью (owner/member), связывающая User и Project.
- Эндпоинт создания проекта: принимает название, создаёт проект с автогенерируемым уникальным кодом, создателя делает owner.
- Эндпоинт получения списка проектов текущего пользователя (owner или member).
- Валидация: название проекта обязательно.
- Гарантия уникальности кода проекта при генерации (повторная генерация при коллизии).

## Не в скоупе

- Присоединение к проекту по коду и заявки (отдельный PRD).
- Одобрение/отклонение заявок (отдельный PRD).
- UI/страницы — только API.
- Редактирование/удаление проекта, смена владельца, регенерация кода.
- Роли отличные от owner/member.

## Технические ограничения

- Код проекта: 8 символов (латиница + цифры), уникален в рамках системы.
- Идентификаторы — UUID, по аналогии с существующей моделью User.
- Роуты проекта защищены JWT; текущего пользователя middleware определяет из токена.

## Критерии готовности

- [ ] Неавторизованный запрос на создание/получение проектов возвращает ошибку авторизации.
- [ ] Авторизованный пользователь может создать проект с названием и получить в ответе сгенерированный уникальный код.
- [ ] Запрос на создание проекта без названия возвращает ошибку валидации, проект не создаётся.
- [ ] Созданный проект имеет ровно одного owner — пользователя, создавшего проект.
- [ ] Авторизованный пользователь получает список проектов, где он owner или member.
- [ ] Два проекта не могут иметь одинаковый код.
