# PRD: Home Page Analytics

**Дата**: 2026-08-24
**Статус**: Draft

## Цель

Дать залогиненному пользователю единую стартовую страницу со сводкой по задачам во всех его проектах, чтобы сразу было видно общий прогресс, не заходя в каждую доску по отдельности.

## Пользовательские сценарии

- Пользователь логинится -> попадает на `/homepage` -> видит общую сводку по всем своим проектам: сколько всего задач, сколько в каждом статусе, какой % выполнено.
- Пользователь видит на `/homepage` список своих проектов с краткой разбивкой по статусам задач в каждом из них.
- Пользователь кликает на проект в этой сводке -> переходит на доску этого проекта (`/dashboard/:projectId`).
- Пользователь, у которого пока нет ни одного проекта, видит на `/homepage` пустое состояние без ошибок.
- Неавторизованный пользователь пытается открыть `/homepage` -> перенаправляется на страницу входа.

## В скоупе

- Сводные метрики по всем проектам пользователя: общее количество задач, количество по каждому статусу (Backlog/To Do/In Progress/In Review/Done), % выполненных.
- Список проектов пользователя с мини-разбивкой по статусам задач для каждого.
- Переход из сводки конкретного проекта на его доску.
- Пустое состояние для пользователя без проектов или без задач.
- Защита страницы: доступ только для авторизованных, редирект на login при отсутствии валидной сессии.

## Не в скоупе

- Сайдбар, список/поиск/создание проектов, вступление по коду, заявки — отдельная фича (`docs/prd-sidebar-navigation.md`).
- Сама канбан-доска и CRUD задач — отдельная фича (`docs/prd-project-dashboard.md`).
- Фильтрация аналитики по датам/периодам, графики/чарты, экспорт отчётов.
- Аналитика по конкретному участнику (кто сколько закрыл задач).

## Технические ограничения

- Требует новой сущности `Task` и её статусов в базе данных (зависимость от `docs/prd-project-dashboard.md`).
- Нужен новый агрегирующий backend-эндпоинт: сводка по задачам во всех проектах, где пользователь — participant (owner/member), плюс разбивка на уровне отдельного проекта.
- Доступ к странице и вызов эндпоинта аналитики требуют валидного JWT.

## Критерии готовности

- [ ] Авторизованный пользователь видит на `/homepage` общее количество задач и % выполненных по всем своим проектам.
- [ ] Пользователь видит разбивку количества задач по каждому из 5 статусов.
- [ ] Пользователь видит список своих проектов с мини-разбивкой по статусам для каждого.
- [ ] Клик по проекту в сводке переводит на его доску `/dashboard/:projectId`.
- [ ] Пользователь без проектов/задач видит пустое состояние без ошибок и падений страницы.
- [ ] Неавторизованный пользователь при переходе на `/homepage` перенаправляется на login.
